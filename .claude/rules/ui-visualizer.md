# UIVisualizer (`Tools/UIVisualizer`)

- 역할: 같은 JSON에서 만든 하나의 UI를 Claude에게는 텍스트(피드백 데이터)로, 사람에게는 화면(DxRender)으로 보여 준다. 편집 도구가 아니다. JSON을 고치는 쪽은 Claude이고 사람은 결과를 눈으로 확인한다.
- 텍스트와 화면은 **같은 UI 인스턴스**에서 나온다. 레이아웃 계산이 한 곳에서만 일어나야 화면과 텍스트가 어긋나지 않는다.
- 피드백 생성 코드는 UI 모듈 쪽에 둔다 (`DxRender`/`DxInput`에 의존하지 않는다). 이 폴더의 실행 파일은 그것을 호출하고 화면에 보여 주는 얇은 막이다.
- 이 폴더에는 테스트 프로젝트를 두지 않는다. 엔진에 없는 실제 로직(undo/redo, 속성-위젯 값 연결, 선택 상태, 좌표 변환, 피드백 계산 등)이 생기면 `Client`, `Core`, `UserInterface`처럼 맞는 프로젝트로 옮길 수 있는지 먼저 검토하고, 옮긴 곳의 기존 테스트 프로젝트에서 테스트한다. 옮기기 어색할 때만 정적 라이브러리와 테스트 프로젝트 분리를 사용자와 논의한다.
- 새 기능은 처음부터 별도 파일로 만들고, `Main.cpp`가 커지면 정리한다.
- Claude에게 주는 피드백은 콘솔이 아니라 **파일**로 출력한다. 루트의 요약 파일(전체 요약과 어느 파일을 보면 되는지 가리키는 포인터)과 주제별 폴더의 상세 파일로 나눠서, Claude가 요약만 읽고 필요한 곳만 따라 들어가게 한다. 항목은 한 줄에 한 가지로 쓰고(Grep 가능), 매번 같은 위치에 덮어쓰며, 위젯 경로와 원본 JSON 파일 이름을 함께 적는다.

## 작업 방식 (사람과 Claude의 분담)

구현 순서와 진행 상태는 `Archives/Todo.txt`가 기준이다. 아래는 지켜야 할 설계 원칙이다.

- **분담**: 사람은 화면을 보고 잘못된 곳만 자연어로 말한다 (렌더링이 이상한지, 모양이 어색한지 눈으로 판단하는 것은 사람의 역할이다). Claude는 JSON을 고친다. 스크린샷은 만들지 않고 Claude가 먼저 요청하지도 않는다. 필요하면 사람이 말한다.
- **JSON이 유일한 기준**: 도구는 JSON을 읽어 그리고, 파일이 바뀌면 자동으로 다시 읽는다. 저장 버튼은 없다. 도구 자신이 쓴 변경은 다시 읽지 않는다.
- **편집 UI 없음**: 속성 패널 같은 값 편집은 두지 않는다. 사람의 직접 조작은 선택한 위젯의 키보드 미세 이동뿐이다 (화살표 1px, Shift+화살표 8px, Ctrl+Z 되돌리기). 이동한 오프셋은 JSON에 바로 쓴다. 앵커/오프셋이 아니라 컨테이너(Stack, Group 등)가 배치하는 자식은 오프셋으로 움직일 수 없다.
- **위젯 이름**: JSON의 각 위젯에 `name`을 두고 형제끼리 겹치지 않게 한다. 이름이 없는 위젯은 `종류#순서`로 임시 표기한다 (순서가 바뀌면 달라지므로 중요한 위젯에는 이름을 붙인다).
- **선택과 전달**: 위젯을 선택하면 화면의 그 위젯 옆에 번호(1, 2, ...)를 그리고, 선택 정보 파일에 번호, 경로, 종류, 위치와 크기, JSON 파일 이름, 시각을 적는다. 사람은 화면의 번호로 말하고(예: "1번은 왼쪽으로, 2번은 위로"), Claude는 선택 정보 파일에서 번호를 위젯으로 바꾼다. 번호는 메시지를 보낼 때마다 1번부터 새로 시작한다. 메시지를 보내는 시점에 훅이 선택 정보를 Claude의 입력에 자동으로 넣고 선택 목록을 비운다. 클립보드 복사는 하지 않는다.
- **수정 이력**: 도구가 JSON을 쓰기 전에 이전 파일을 `.history/`에 번호를 붙여 복사하고, Claude도 JSON을 고치기 전에 같은 폴더에 복사한다. 되돌리기는 이 복사본으로 한다. 커밋하면 비운다. `.history/`는 `.gitignore`에 넣는다.
- **확장 (보류)**: 캐릭터 위치, 상점 위치 같은 다른 영역도 같은 방식(선택, 번호, JSON 수정, 키보드 이동)으로 다루고, 영역을 골라 들어가고 돌아오게 한다. 이때 선택/번호/선택 정보/이력/다시 읽기는 영역과 무관한 공통 부분으로 두고, 그리기와 선택 대상 목록과 이동 방법만 영역별로 둔다.
