# UIVisualizer (`Tools/UIVisualizer`)

- 역할: 같은 JSON에서 만든 하나의 UI를 Claude에게는 텍스트(피드백 데이터)로, 사람에게는 화면(DxRender)으로 보여 준다. 편집 도구가 아니다. JSON을 고치는 쪽은 Claude이고 사람은 결과를 눈으로 확인한다.
- 텍스트와 화면은 **같은 UI 인스턴스**에서 나온다. 레이아웃 계산이 한 곳에서만 일어나야 화면과 텍스트가 어긋나지 않는다.
- 피드백 생성 코드는 UI 모듈 쪽에 둔다 (`DxRender`/`DxInput`에 의존하지 않는다). 이 폴더의 실행 파일은 그것을 호출하고 화면에 보여 주는 얇은 막이다.
- 이 폴더에는 테스트 프로젝트를 두지 않는다. 엔진에 없는 실제 로직(undo/redo, 속성-위젯 값 연결, 선택 상태, 좌표 변환, 피드백 계산 등)이 생기면 `Client`, `Core`, `UserInterface`처럼 맞는 프로젝트로 옮길 수 있는지 먼저 검토하고, 옮긴 곳의 기존 테스트 프로젝트에서 테스트한다. 옮기기 어색할 때만 정적 라이브러리와 테스트 프로젝트 분리를 사용자와 논의한다.
- 새 기능은 처음부터 별도 파일로 만들고, `Main.cpp`가 커지면 정리한다.
- Claude에게 주는 피드백은 콘솔이 아니라 **파일**로 출력한다. 루트의 요약 파일(전체 요약과 어느 파일을 보면 되는지 가리키는 포인터)과 주제별 폴더의 상세 파일로 나눠서, Claude가 요약만 읽고 필요한 곳만 따라 들어가게 한다. 항목은 한 줄에 한 가지로 쓰고(Grep 가능), 매번 같은 위치에 덮어쓰며, 위젯 경로와 원본 JSON 파일 이름을 함께 적는다.
